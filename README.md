
🍕 Pizza Hut Sales Analysis - Power BI Dashboard


This Power BI project presents a detailed sales analysis for Pizza Hut. It includes insights on revenue, top-selling products, sales trends, customer behavior, and regional performance. The dashboard is designed to help business stakeholders make data-driven decisions.



## 1. 📊 Dashboard Features

## 📊 Key Features

- Total Sales and Revenue Overview
- Monthly Sales Trend
- Top-Selling Pizza Products
- Customer Insights (Repeat vs New Customers)
- Regional Sales Performance
- Interactive Filters for Custom Analysis
