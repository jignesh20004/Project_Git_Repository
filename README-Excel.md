
# 📊 Title: Finance Performance Dashboard

This Excel dashboard provides a comprehensive overview of key financial metrics using pivot tables and interactive visualizations. It is designed to offer quick insights into revenue, expenses, profitability, and other critical KPIs. The dashboard supports strategic decision-making by presenting data in a clear, interactive, and visually compelling format.



## 1. 📊 Dashboard Features

Key Features:

Dynamic pivot charts

Monthly/quarterly financial trends

Expense vs. revenue breakdown

Clean, professional layout with slicers for filtering

## 3. Tools & Technologies Used

| Tool / Technology          | Purpose & Use Case                                                                 |
| -------------------------- | ---------------------------------------------------------------------------------- |
| **Microsoft Excel**        | Primary platform for creating the interactive dashboard                            |
| **Pivot Tables**           | Used to summarize and analyze large datasets for key metrics                       |
| **Pivot Charts**           | Visual representation of profit, sales, and discount metrics                       |
| **Slicers**                | Added for interactive filtering by year, country, and segment                      |
| **Formulas**               | Applied to calculate total profit, discounts, and average metrics                  |
| **Data Visualization**     | Line, bar, column, and pie charts used to show monthly trends and segment analysis |
| **Conditional Formatting** | Used to enhance visual cues and interpretability                                   |
