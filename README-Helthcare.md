
# 🏥 Healthcare Analytics Dashboard – Power BI

This Power BI project delivers an in-depth analysis of healthcare operations. It includes key metrics such as patient volume, treatment outcomes, department performance, and resource utilization. The dashboard is designed to support hospital administrators and decision-makers by offering actionable insights, improving efficiency, and identifying trends in healthcare services.


## 1. 📊 Dashboard Features

📊 Key Features: Healthcare Insights Dashboard
This Power BI dashboard provides a comprehensive analysis of patient data, medical conditions, and hospital performance. It is designed for actionable insights in healthcare management and monitoring.

🧠 Overview Insights
👥 Total Patients: 56K+ patients tracked

👨‍⚕️ Total Doctors: 15K+ professionals involved

💸 Total Billing: $474M in healthcare services

🛏️ Bed Occupancy: 14.78K beds actively used

🩺 Medical Condition Analysis
📌 Top Conditions Monitored: Diabetes, Cancer, Arthritis, Asthma, Hypertension, Obesity

🧪 Test Result Status: Visualized via Sankey chart – Normal, Abnormal, Inconclusive

📈 Discharge Breakdown: Condition-wise discharge count – highest for Arthritis & Diabetes

🏥 Hospital & Doctor Performance
👨‍⚕️ Doctor-Wise Insights: Total patients treated & billing amount per doctor

🏨 Hospital-Wise Room Count: Comparison of available rooms by hospital

📊 Bed Occupancy by Admission Type: Elective, Emergency, Urgent across multiple hospitals

🧬 Comparative Analysis – Cancer vs Asthma
📆 Year-Wise Admission & Discharge Trends (2019–2024)

📊 Side-by-Side Comparison:

Asthma: ~9185 patients

Cancer: ~9227 patients

🧾 Additional Filters & Segmentation
🔘 Gender & Blood Type Filtering

📅 Year-Wise Admission Trends

🚨 Admission Type Segregation: Elective, Emergency, Urgent
